title: Support parallel task worktrees with explicit integration context
status: accepted
paths: [spec/worktrees.md]
---

User direction, 2026-09-24: a plan may be executed by many agents in separate
worktrees, then integrated into the main project. Worktree records describe
proposals; the integration branch supplies accepted state. Task status and an
optional assignee in each worktree describe current work. Duplicate assignments
are visible overlaps, not enforced locks. No coordination service or MCP is
required. Every writing interface identifies the checkout. Code and task changes
integrate through normal Git operations, with conflicts visible.
