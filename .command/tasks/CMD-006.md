User decision: Command Center is one project dashboard with its entire .command
tree on an independent command branch. Code worktrees contain code, not copies of
the plan. Do not create a sibling planning directory. Use ordinary Git operations
without a checkout; MCP, CLI and UI offer convenient validated CRUD over the same
branch. Explicit task branch/commit links connect the plan and implementation.

Acceptance: four independent worktrees visible concurrently, activity in task
rows and graph, no branch switching needed, canonical definitions remain central,
no hidden per-worktree task state, expected-revision conflicts prevent overwrites,
code HEAD/index/dirty files remain untouched, and old self-tracking state is backed
up and migrated without rewriting code history.
