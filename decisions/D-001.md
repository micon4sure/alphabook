User direction, 2026-09-24: build a new small project-management Command Center at
/backup/_HOT/command. Keep tasks, decisions, documentation and artifacts in the
managed project's repository; support files and MCP. Command is a viewer/editor
for that data, with its own independent source repository. GitHub is optional.

Formalize an open format usable by other tools. Its current name and version are
experimental. The app must not require an agent runner or own managed project code.
