status: accepted

The user chose Alphabook and explicitly rejected backwards-compatibility aliases.
The dedicated orphan branch is alphabook. It directly contains project.yaml,
tasks/, decisions/, docs/ and artifacts/; a dot-folder adds no value here.

Format 0.3, CLI, MCP, configuration, installation and service use the new name.
Keep one shared plan for all code worktrees, ordinary Git CRUD and optional MCP.
Preserve project UUIDs, record IDs and Git history. Historical records retain their
original wording; the current tree and reference documentation use the new layout.

DOMINATION is explicitly excluded from migration. Its files and refs remain
unchanged, and the new reader will report its unsupported plan until migrated.
