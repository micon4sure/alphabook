User clarification, 2026-09-24: all planning is file based. MCP is only a
convenience for writing `.command` planning files and committing those changes.
Command Center shows the current state and may offer edits, but the entire system
must remain usable without MCP. Single-checkout and multiple-worktree tracking use
the same records. Live assignment/claim coordination is not a core requirement.
