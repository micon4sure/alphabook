Define a small versioned format usable independently of Command Center. Include
repository-owned tasks, decisions, docs/artifacts, Git commit associations and
parallel worktree semantics. Provide schemas, examples and a read-only validator.

Acceptance: examples validate; invalid metadata/references/cycles are diagnosed;
accepted branch state is distinguished from worktree proposals; ordinary file/Git
operation works without MCP or a coordination service. Commit with Task: CMD-001.

The web app and optional MCP planning adapter are subsequent implementation work.
Claim services and automatic integration queues are outside the current scope.
Nothing is published or migrated as part of this draft.

Delivered: versioned draft, JSON Schema, self-tracking and example records,
read-only Python validator, and 14 passing tests including a real Git worktree
and integration flow without MCP. See the validation artifact for exact scope.
