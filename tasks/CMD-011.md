## Outcome

Preview supported image files directly in the Artifacts view while keeping
artifact access scoped to committed files in the selected Alphabook snapshot.

## Acceptance

- PNG, JPEG, GIF and WebP artifacts render in the artifact detail panel.
- Artifact bytes are served only for an exact listed artifact and snapshot.
- Unsupported binary files and Git LFS pointer files are not presented as images.
- Server, browser and type-check verification cover the behavior.

## Delivered

The Artifacts view now previews signature-identified PNG, JPEG, GIF and WebP
files from an exact Alphabook commit and SHA-256 revision. The loopback server
only serves listed files under `artifacts/`; text, LFS pointers, spoofed image
extensions, wrong revisions and paths outside the artifact tree are rejected.

The UI uses a responsive contained image panel with a transparency checkerboard.
The browser test loads a real PNG and verifies its natural dimensions. See the
validation record and captured preview for evidence.
